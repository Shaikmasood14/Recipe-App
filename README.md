# Recipe Application

## About
A Flutter application for discovering and
exploring different recipes.

## Features
- User Login
- View Recipes
- Search Recipes
- Like Favorite Recipes
- View Recipe Ingredients
- Cooking Instructions

## Technologies Used
- Flutter
- Dart
- Firebase

## How to Run
1. Install Flutter.
2. Open the project in VS Code.
3. Run flutter pub get.
4. Run flutter run.# Recipe-App
Flutter Recipe Application
